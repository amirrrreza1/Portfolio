# M7 — Portfolio CMS

Status: **In progress**  
Snapshot: **2026-08-27**  
Depends on: M2, M3, M4, M5, M6

## Delivered so far

The first vertical slice — site shell administration — is implemented at the
authenticated API boundary:

- strict shared contracts for site settings, per-locale site text, appearance,
  page sections, navigation, and social links;
- owner-authorized `/admin` reads and mutations with a session check, CSRF and
  origin validation, `private, no-store` responses, and `If-Match` optimistic
  concurrency;
- every successful mutation writes a versioned content revision and a redacted
  audit event plus durable, locale-scoped public cache invalidation events in
  the same database transaction; and
- section, navigation, and social-link writes preserve the public renderer's
  closed key, route, URL, and icon constraints.

ADMIN-003's dashboard is also now live in the authenticated shell. It exposes
only safe counts and event categories: drafts, scheduled translations, retained
contact-message count, recent edits, failed security events, and the
publication/invalidation queue state. It deliberately does not surface content
bodies, audit metadata, credentials, storage keys, or client fingerprints.

The skills/projects slice now provides strict API operations for skill
categories and their translations, proper-noun skills, projects, project
translations, and ordered project-skill relations. Project links are replaced
inside the same version-checked transaction as the project record, so a stale
editor cannot partially reorder a newer project. An authenticated UI currently
supports adding categories and skills and makes the existing structure visible;
full edit controls, archive behavior, and the remaining resource families are
still open.

Certificates and daily quotes now also have owner-authenticated list/create/
update API operations. Certificate metadata and each locale's title/description
are independently versioned, while quotes retain their intentionally nullable
author and safe localized-text map. Their admin UI, archive/restore controls,
and verified media attachment flow remain part of the open media slice.

The API route set is intentionally not yet a claim that M7 is complete: the
administrative UI and the remaining content, media, restoration, and health
slices still need to be delivered and live-proven.
