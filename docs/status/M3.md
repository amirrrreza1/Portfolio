# M3 — PostgreSQL-native article foundation

Status: **In progress**

## Current position

The previous Git-backed M3 implementation and its 2026-08-24 live run are superseded architectural history. The platform now requires complete Markdown article bodies, localized metadata, publication state, source/render integrity, optimistic versions, and revision history to be authoritative in PostgreSQL. MinIO remains responsible only for binary media.

The safe production Markdown renderer, strict editorial contracts, durable PostgreSQL job primitives, advisory locking, signed cache invalidation, and bilingual public-read surfaces are reusable. GitHub App authentication, content-branch protection, inbound content webhooks, Git synchronization/drift states, apply ledgers, operation records, and cross-system reconciliation are no longer deliverables.

## Required deliverables

- Reviewed forward Prisma migration adding authoritative translation Markdown and SHA-256 source integrity, replacing draft blob tokens with integer base versions, and removing Git-only synchronization structures.
- Safe treatment of legacy indexed articles: historical rows without recoverable Markdown are never silently reconstructed or published; they remain unavailable until explicitly reimported.
- Server-only transactional article repository validating locale/editorial identity, existing taxonomy/media references, production Markdown rendering, source digests, and expected translation versions.
- Atomic persistence of source, metadata, sanitized render cache, translation version, immutable revision history, and signed-invalidation outbox intent.
- PostgreSQL-backed scheduled-publication jobs and single advisory-lock scheduler with bounded retries and idempotent processing.
- Tests for bilingual saves, stale-version conflicts, invalid references/Markdown, rollback, source/render integrity, revision creation, scheduling, and outbox delivery.
- A real PostgreSQL-backed English/Persian article exercised through the public-read path.

## Remaining exit gate

M3 remains open until a real PostgreSQL environment proves bilingual authoritative Markdown persistence, matching source digests and safe renders, version-conflict rejection, immutable revisions, transactional rollback/outbox atomicity, and idempotent database-native publication. A unit suite or historical Git-backed run does not close this gate.
