# M8 — Blog authoring, publishing, and SEO

Status: **In progress**
Snapshot: **2026-08-28**
Depends on: M3, M4, M6, M7

## Delivered so far

**The authenticated blog authoring boundary**, proven against a running stack in
[`evidence/M8-blog-authoring-live.md`](evidence/M8-blog-authoring-live.md) — 25
checks, re-runnable as `pnpm --filter @portfolio/api verify:blog`.

M3 built the article authority and M4 proved the public reads, but nothing let a
person reach either: `packages/contracts/src/blog/commands.ts` had described
every command since M3 while `publish`, `schedule`, `unpublish`, and `archive`
went unimplemented, no endpoint addressed a translation, and `PUBLISH_BLOCKERS`
was eleven constants nothing computed. This slice closes that gap.

- **Editorial state transitions as commands**, per API_SPEC §6 — publish,
  schedule, unpublish, archive — each with its own preconditions, audit event,
  and invalidation urgency, rather than one diff-driven status patch.
- **A publish checklist that is actually evaluated.** A pure evaluator in
  `@portfolio/contracts` turns gathered facts into blockers and warnings;
  blockers refuse, warnings must be acknowledged by name. `inspectArticleSource`
  in `@portfolio/markdown` reports what the render pipeline would _throw_ on, so
  the checklist can describe a body that is not ready yet.
- **Autosave** to `PostDraft` with no version check and no path to publication,
  reported to the editor beside the committed body rather than merged into it.
- **Slug history.** A slug change writes a `308` in the same transaction, and a
  second move collapses the chain instead of adding a hop.
- **Blog taxonomy CRUD** — the only way a category or tag comes into being,
  which is what makes the article store's refusal to create one implicitly safe.
- **Preview** through the production pipeline, held in memory under an
  unguessable short-lived token, never persisted.

Every transition writes an immutable revision, a redacted audit event, and a
durable invalidation outbox row inside the transaction that changed the state.

## Also delivered, outside the slice

- **The admin request boundary is shared** between the M7 and M8 controllers.
  M7's proof was re-run against the refactor: 31/31, unchanged.
- **The M5 prose gap is closed.** The reading surfaces carry explicit
  token-built element rules instead of a `prose` class that emitted nothing, and
  the e2e fixture body now contains a heading, list, blockquote, inline code,
  and a link so the appearance matrix can see article typography at all.

## The defect the live run found

`archive` enqueued an invalidation whose `reason` the signed-event contract does
not define, and every archive failed with a `500` inside its transaction. The
lifecycle module had declared the reason union by hand and added a value the
contract lacked; TypeScript was satisfied because the local type was internally
consistent. The type is now derived from the contract, and archive enqueues
`unpublish` — accurate, because archiving has no cache behaviour of its own.

The same run found that the failure was undiagnosable: the exception filter
answered `500` and logged nothing. It now logs the stack for any unmapped
exception.

   transactional-rollback proof for the scheduled path.
