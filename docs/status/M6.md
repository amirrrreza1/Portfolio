# M6 — Authentication foundation

Status: **In progress**  
Snapshot: **2026-08-14**  
Depends on: M1  
Roadmap: [M6 definition and exit gate](../ROADMAP.md#m6--authentication-foundation)

## Outcome so far

The reusable authentication primitives and several Prisma adapters exist. The public API boundary, full WebAuthn verification, authorization/audit layer, admin shell, and operational recovery proof remain open.

## Delivered

- Opaque keyed session and CSRF token primitives.
- Argon2id password hashing and non-enumerating password-step behavior.
- Hashed single-use recovery codes.
- Single-use WebAuthn challenge creation/consumption primitives.
- Cookie-mutation CSRF/origin guards.
- Explicit-apply owner provisioning gated by bootstrap file and expiry.
- Prisma persistence adapters for password sessions and WebAuthn challenges.
- Contract and auth-core unit suites covering these primitives.

- Implementation/tests: [`packages/auth-core`](../../packages/auth-core)

## Outstanding gate work

- API password-login, session, CSRF, logout, re-auth, recovery, and WebAuthn enrollment/assertion endpoints.
- Full WebAuthn cryptographic verification with RP ID/origin/counter/replay enforcement.
- Throttling, session rotation/revocation, recent-auth rules, and security notifications.
- Deny-by-default role/object authorization policies and negative tests.
- Structured redacted audit events and admin/auth CSP/header behavior.
- Authenticated admin shell with no content mutation capability until the gate passes.
- Repeatable owner recovery and credential-revocation drill.
