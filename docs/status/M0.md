## Delivered

- Captured the pre-stabilization routes, 137 source/asset hashes, content counts, and original font inventory in [BASELINE_M0.md](../BASELINE_M0.md).
- Added CI for frozen install, formatting, lint, typecheck, real tests, production builds, and full-history secret scanning.
- Removed `--passWithNoTests`; real web and API suites exist.
- Set Next.js standalone output and `metadataBase`/canonical site URL handling.
- Kept Zod as the application validation stack; removed direct class-validator/class-transformer use.
- Replaced `NEXT_PUBLIC_BIRTHDAY` with server-only `BIRTH_DATE` and deterministic UTC age logic.
- Corrected certificate path casing and added case-sensitive asset validation.
- Removed `.eot`, `.ttf`, and `.woff` duplicates; retained `woff2` assets with corrected numeric weights.
- Removed browser-side EmailJS usage and later replaced contact submission with a server-side API/SMTP path.
- Accepted ADR-009–ADR-014 for appearance delivery, Persian slugs, content branch protection, cross-store recovery, worker topology, and API outage behavior.
- Added LF/formatting guardrails so Windows and CI evaluate the same source.
