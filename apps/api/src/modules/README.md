# API modules

Delivered modules currently include the health probe, server-side contact delivery, and strict public reads for project lists, the localized site shell/ordered page sections, appearance, homepage collections, certificates, and the active resume. The site read validates Hero/About through the restricted Markdown renderer, derives age from the private database date, and returns neither that date nor an unresolved template token. It also exposes only the public GitHub username, exact repository allowlist, and bounded cache TTL consumed by the web server's outbound statistics adapter; no token enters the DTO. Public media routes authorize database references and mediate private MinIO reads; no object key or storage credential enters a DTO. Module boundaries and endpoint ownership are defined in `docs/ARCHITECTURE.md` and `docs/API_SPEC.md`.
